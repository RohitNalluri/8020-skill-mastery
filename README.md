# 8020

## Status

Paused as of September 2026. This is a working prototype, not a product. Plan generation, the daily One Thing view, and the session/journal loop all run end to end. The two things that would make it useful are: the resource links that a plan hands the user today are unverified (the model invents them), and there's no real deconstruction step behind the 80/20 framing, just a prompt asking for a 30-day plan.

The goal, if this gets picked back up, is a course generator that does what Josh Kaufman's 20-hours method describes: take a skill, break it into its real parts, cut everything but the roughly 20% that gets someone functional, and hand back a short, trustworthy path instead of a generic syllabus. A second mode has been sketched for open-ended learning, a month spent going broad on a topic out of curiosity and closing with a compressed summary rather than a demonstrated skill, but nothing for it has been built.
